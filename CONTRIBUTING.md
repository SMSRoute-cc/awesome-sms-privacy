# Contributing

1. One service per pull request.
2. State: name, URL, whether ID documents are required, payment methods, coverage, price per SMS, and the date you checked.
3. No affiliate links. No unverified claims ("best", "fastest", "guaranteed").
4. Services that only **receive** SMS belong in a separate section and must be labelled as such.
5. Entries without a price or without a stated requirement will be removed.
